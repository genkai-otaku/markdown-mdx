# マークダウンの書き方

Markdown は、普通のテキストで見出し・リスト・リンクなどを書く記法です。各節は、コードブロックが書き方、その下の枠が **プレビュー** です。

## 見出し

`#` の数が見出しのレベルです。題名は `#`、節は `##`、小節は `###` にします。

```md
# h1
## h2
### h3
```

`#` と `##` はこのページの見出しになるので、プレビューは `###` だけ出します。

<Preview>
### h3
</Preview>

## 段落

空行を挟むと段落が分かれます。改行しただけでは、同じ段落のままつながることが多いです。

```md
ひとつめの段落です。

ふたつめの段落です。
```

<Preview>
ひとつめの段落です。

ふたつめの段落です。
</Preview>

## 強調

```md
**太字**、*斜体*、***太字かつ斜体***、~~打ち消し~~
```

<Preview>
**太字**、*斜体*、***太字かつ斜体***、~~打ち消し~~
</Preview>

`**` と `*` の代わりに `__` と `_` も使えます。

## リスト

```md
- りんご
- みかん
    - 温州
    - ポンカン
- ぶどう

1. 切る
2. 煮る
3. 盛る
```

## リンク

```md

```

## 画像

```md
![サイトのアイコン](/favicon.svg)
```

<Preview>
![サイトのアイコン](/favicon.svg)
</Preview>

書き方はリンクに `!` を付けたものです。`[]` が代替テキスト、`()` が画像の場所です。

## コード

文中のコードはバッククォート 1 つで囲みます。例: `package.json`。

複数行はバッククォート 3 つで囲み、言語名を付けられます。

````md
```js
const hi = 'こんにちは'
console.log(hi)
```
````

<Preview>
```js

console.log(hi)
```
</Preview>

## 折りたたみ（アコーディオン）

Markdown 自体にアコーディオンの記法はありません。GitHub やこのサイトでは、HTML の `<details>` が使えます。

```html
<details>
<summary>クリックして開く</summary>

中に書いた文章です。**強調**も使えます。

</details>
```

<Preview>
<details>
<summary>クリックして開く</summary>

中に書いた文章です。**強調**も使えます。

</details>
</Preview>

`</summary>` のあとに空行を入れると、中身でも Markdown が使えます。対応していない変換器もあります。

## 区切り線

ハイフン・アスタリスク・アンダースコアを 3 つ以上、単独の行に置きます。

```md
上の段落

---

下の段落
```

<Preview>
上の段落

---

下の段落
</Preview>

## エスケープ

記号そのものを出したいときは、直前に `\` を置きます。

```md
\# これは見出しではない
\*アスタリスク\*
```

<Preview>
\# これは見出しではない

\*アスタリスク\*
</Preview>

## これだけ覚えておけば足りること

- ブロック（見出し、リスト、コード、引用、表）の前後は空行を空ける
- 文中の装飾は `**太字**`、`` `コード` ``、`[文言](URL)` が中心
- 表・タスクリスト・打ち消し線は GFM。折りたたみは HTML の `<details>`
- GitHub やこのサイトでは、上の記法が使えます

文章の途中にボタンなどの UI を置きたいときは [MDX](/mdx) を使います。
