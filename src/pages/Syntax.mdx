# MDX の書き方

こんにちは、**{props.name}** さん。`App.tsx` から渡した `name` が、この一文に入っています。

## Markdown はそのまま

段落、**強調**、*斜体*、`インラインコード`、[リンク](https://mdxjs.com/) が使えます。

- 箇条書き
- もう一つ

1. 番号付き
2. リスト

> 引用も普通の Markdown です。

## JSX を混ぜる

文の途中に <Badge>MDX 内で定義したバッジ</Badge> を置けます。上の `export function Badge` がそれです。

```mdx
export function Badge({ children }) {
  return (
    <span className="badge">{children}</span>
  )
}
```
